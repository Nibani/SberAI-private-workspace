# Что готово и что осталось

| Часть проекта | Состояние |
|---|---|
| Исходные данные | Получены и проверены; числа CSV и Parquet совпадают |
| Идентификаторы территорий | Используется официальный territory_id и годовой справочник |
| Признаки и сеть | Построены все 24 месячные сети |
| Методология | Описаны признаки, сходство и порядок проверки |
| Сравнение алгоритмов | Код готов; расчёты ещё впереди |
| Метрики | Реализованы SW, CH, S_Dbw, AVI и AVU; формулу MQ нужно уточнить |
| Проверки реализации | 18 тестов пройдены |
| Экономическая интерпретация | Предстоит после сравнения алгоритмов и получения внешних данных |
| Атлас | Локальный прототип с рядами расходов и экономическими соседями |
| Воспроизводимость | Код, конфигурации, ссылки на источники и хеши файлов сохранены |

Ближайший шаг — небольшой сравнительный запуск за декабрь 2023 года. После него можно выбирать настройки и переходить к проверке устойчивости.

До выводов о переходах между типами нужно разобраться с изменениями границ за 2024 год. Для внешней проверки нужны муниципальные показатели занятости или зарплат с ясными определениями и надёжным сопоставлением территорий.

Текущая версия отражает этап подготовки. Итоговые кластеры, экономические кейсы и финальные материалы для конкурса ещё не готовы.
