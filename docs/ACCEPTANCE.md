# Материалы по критериям конкурса

Здесь собраны результаты для проверки проекта по шести критериям Положения. Веса указаны по пункту 6.1; шкала и описание уровней находятся в пункте 6.3 и приложении 1. [Положение конкурса](https://sber.ru/common/assets/sber/sberindex_polozhenie_o_konkurse.pdf).

| Критерий | Вес | Что посмотреть | Что учитывать |
| --- | ---: | --- | --- |
| Простота объяснения методологии | 15% | [От признаков к сети, группам и аналогам](NETWORK_TYPOLOGY.md) | Основная совместная модель α=0,5 использует пять отношений расходов и их общий уровень; прежние модели находятся в Архиве v1.1 |
| Сетевая и атрибутивная структура | 15% | [Девять правил построения рёбер](NETWORK_TYPOLOGY.md#девять-правил-рёбер) | Рёбра описывают сходство расходов; выбор использовал изученные 2023–2024 годы |
| Сравнение методов | 15% | [Выбор четырёх групп](NETWORK_TYPOLOGY.md#почему-четыре-группы), [Чувствительность выбора](../reports/v1.2-method-ties/README.md) | Семейство выбрано устойчиво (99,4%), точное α — нет (57,2%); варианты различаются у 17–38 МО. Это ранжирование фиксированных разбиений на 500 региональных подвыборках, без переобучения |
| Использование ICVI | 15% | [Шесть показателей для вариантов основной модели](../reports/v1.2/methods.csv), [прежнее сравнение](../reports/icvi-2026-10-07/README.md), [формулы](METRICS.md) | Формула конкурсного MQ требует уточнения; используемые определения названы явно |
| Интерпретация, ясность и воспроизводимость | 30% | [Применение аналогов](NETWORK_TYPOLOGY.md#как-использовать-аналоги), [основные расчёты](../reports/README.md), [команды](REPRODUCE.md) | Уровень расходов оценивает зарплату точнее групп: R² 0,734 против 0,430. [Новая проверка](../reports/v1.2-added-value/README.md): после поправки на восемь исходов прирост сверх сплайна значим только для добычи, после поправки на 48 проверок значимого прироста нет; сверх долей выигрыш не подтверждён |
| Инновационная визуализация | 10% | [Атлас](index.html): карта, профили, аналоги, сеть и изменения по месяцам | Полнота внешних показателей различается между территориями |

Национальные данные по зарплатам и отраслевым показателям собраны; их охват и пропуски описаны в [отчёте по внешним источникам](../reports/external-national-2026-10-03/README.md). Точность аналогов проверяется в процентных пунктах роста на общей выборке. Для оценки переноса между регионами сохранена [проверка с исключением региона из всей процедуры](../reports/v1.2/strict-region-validation/summary.json).

Проверку сохранённых моделей можно запустить по [инструкции технической приёмки](TECHNICAL_ACCEPTANCE.md). Датированные протоколы в `reports` относятся к указанным в них версиям. Эта страница помогает найти подтверждения; баллы выставляет жюри.
