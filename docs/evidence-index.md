# Научные свидетельства

Текущие исходные данные, таблицы основного атласа и материалы прямых ссылок остаются обычными файлами в `data/` и `reports/`. Результаты новых опытов находятся отдельно в `reports/temporal-v4/` и `reports/conditional-v4/`.

## legacy

[Полный исторический ZIP](../archive/legacy-evidence.zip) содержит все **432 отчёта** исходного публичного снимка `0a17136d76e207c9866f7ffd238e6b51ebf7b001`, включая неудачные опыты, прежние отрицательные результаты и материалы происхождения. Каждый член имеет прежний полный путь, например `reports/v1.2/strict-region-validation/fold_000.json`. [Manifest](../archive/legacy-evidence.manifest.json) даёт точный состав, размер, SHA256 и список материалов, которые также оставлены обычными файлами. Архивирование не изменяет старую науку и её формулировки.

SHA256 ZIP: `cecccafbeade2970f923e0cf9fe97bf96005914c66056aa394f2db1507789bb8`; размер 12 299 409 байт. Проверка отвергает пропуски, лишних/повторных членов, небезопасные пути, ссылки, изменённые байты и ошибки CRC.

```sh
python -m scripts.logical_storage
python -m scripts.logical_storage --materialize artifacts/legacy-evidence
```

После второй команды любой прежний путь открывается под `artifacts/legacy-evidence/`. `run_all.py` выполняет такое восстановление автоматически в своём runtime. Архивные ссылки приводят к этому указателю, поскольку статический браузер не может открыть отдельный член ZIP как обычный файл.

Основные сохранённые пакеты: `v1.2` — методы, ICVI, сети, аналоги и историческая динамика; `v1.2-added-value` — проверки добавочной ценности и отрицательные сравнения; `v1.2-method-ties` — 500 draws и размен между индексами; `competition-enhancement` — синтетика, устойчивость, экономические кейсы и ограничение недоступной мобильности; `technical-core-2026-10-03` и `temporal-core-2026-10-03` — прежние технические и временные опыты. Эти названия описывают сохранённую историю, а не текущую научную приёмку.

## Подробности временного опыта

Сводки и наблюдаемые данные находятся в `reports/temporal-v4/`: `summary.json`, `curves.json`, registration/selected/source-manifest, `real-correction.json`, `real-monthly-projections.csv` и постоянная контрольная fixture. Все 80 подробных checkpoints и повторяющая их события таблица `events.csv` сохранены в отдельном [ZIP](../archive/temporal-v4-details.zip) с отдельным [manifest](../archive/temporal-v4-details.manifest.json); этот архив не изменяет исторический ZIP из раздела выше. Manifest сохраняет исходные logical paths, все размеры и SHA. Упаковка не меняет результаты, source pins или отрицательный научный gate.

В сохранённой схеме событий поле `censored` означает сегмент короче шести месяцев, включая короткие внутренние сегменты. Название неточно: это не всегда цензурирование краем наблюдений. Для подсчёта устойчивых изменений используются `persistent` и `persistent_boundaries`; эта оговорка не меняет их значения, метрики или отрицательный итог проверки детектора.

81 файл занимает в архиве 15 872 147 байт вместо 92 935 489 байт. SHA256 ZIP: `671eddaf8f03c2ac132b424043b8bce0e10a0e39e18e2acd81b35803b36fcb5c`. Проверены все исходные байты, CRC и неизменность закреплённых исходников. Сводки и наблюдаемые данные остаются обычными файлами.

```sh
python -B -X utf8 -m scripts.verify_current_results --only temporal
```

Wrapper автоматически проверяет и восстанавливает подробные файлы в отдельный runtime, затем запускает неизменный исходный verifier. Общий `scripts.logical_storage --materialize` также восстанавливает его вместе с историческим. Полный `run_all` использует этот же слой хранения.
