# Метрики и их ограничения

Основной источник для атрибутивных сетей: https://link.springer.com/article/10.1134/S1064562425700589 . Формулы прочитаны, но статья не заменяет спецификацию конкурса. Все методы оцениваются на одном наборе объектов, одинаковом пространстве признаков и одном опорном графе для данного месяца.

| Индекс | Реализация | Направление |
|---|---|---|
| SW | sklearn silhouette_score, Euclidean, все объекты; singleton по конвенции sklearn | больше |
| CH | sklearn calinski_harabasz_score; одновременно сообщать N и K | больше |
| S_Dbw | population variance ddof=0; плотность внутри замкнутого шара | меньше |
| AVI | у группы: 2×внутренние рёбра / (2×внутренние + исходящие); среднее по K | больше |
| AVU | сумма по упорядоченным парам e_kl/(external_k+external_l−e_kl), делённая на K | меньше |
| MQ | **не определена организаторами**, результат null со статусом | неизвестно |

Для AVI/AVU используется бинаризация весов >0. Внутренние рёбра в симметричной матрице считаются дважды. AVU делится на K, а не K(K−1): это важно для соответствия указанной статье, уравнение 21. Взвешенное обобщение не выдаётся за её определение.

При нулевом знаменателе AVI/AVU выводятся null и число неопределённых членов; не проставляется искусственно идеальный ноль. Для 2≤K<N допустимы атрибутивные метрики; другие разбиения отмечаются явно. MQ не подменяется модульностью Newman Q или ANUI.

S_Dbw: норма вектора дисперсий внутри групп, radius = sqrt(sum(norm(var(C_k))))/K. Scat = mean(norm(var(C_k)))/norm(var(X)); Dens_bw — нормированная попарная плотность около середины центроидов. В статье Shalileh et al. (2026), формула 14, индикатор инвертирован относительно обычного определения плотности. Здесь используется исходная логика Halkidi–Vazirgiannis (2001): 1 при расстоянии ≤radius. Нулевые плотности/общая дисперсия — неопределённость. Оригинальная статья: https://doi.org/10.1109/ICDM.2001.989517 . В этой реализации я трактую расхождение как возможную опечатку; опубликованного исправления от авторов статьи нет.

Тесты проверяют аналитический граф-путь (AVI=2/3, AVU=1), разобщённые компоненты (AVU неопределён), разделённые точечные массы (S_Dbw=0), пустые шары плотности, инвариантность к перестановке меток. Они не сравнивают качество алгоритмов и не запускают обучение.

ARI оценивает совпадение разбиений на общих идентификаторах. Hungarian matched churn используется только как сводка; полная матрица пересечений сохраняется, чтобы не скрыть разделения и слияния. Устойчивость сама по себе не является экономической валидностью.
