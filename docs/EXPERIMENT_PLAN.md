# План экспериментов

Первое небольшое сравнение завершено на январе, июне и декабре 2023 года. [Результаты](../reports/experiments/2026-09-23/README.md) сохранены; дальше я проверю устойчивость к настройкам и случайной инициализации, затем перейду к остальным данным.

## Первый запуск

Конфигурация: `configs/pilot.json`. Декабрь 2023 года, 2 016 территорий, seed = 1729:

- KMeans: 8 групп.
- Ward: 8 групп.
- Leiden: resolution = 1.
- Общая сеть: 15 ближайших соседей.

Восемь групп — стартовая настройка, а не вывод о числе экономических типов. Сначала нужно проверить разбиения, размеры групп и метрики. Если результат вырожден, стоит разобраться с причиной до расширения расчётов.

## Выбор настроек на 2023 году

Сравню несколько чисел групп (4, 6, 8, 12), размеров соседства (10, 15, 30) и три seed для случайных методов. Полный перебор всех сочетаний не нужен: сначала меняется один параметр, затем проверяется небольшой набор удачных вариантов.

При выборе учитываются разделение групп, устойчивость и возможность объяснить результат. Одной высокой модульности недостаточно: сеть ближайших соседей может содержать сообщества даже у непрерывного облака данных.

## Проверка на 2024 году

Настройки фиксируются до анализа 2024 года. Эти месяцы нужны для проверки того, сохраняются ли выводы на другом периоде. Если использовать их для подбора параметров, они перестанут быть отдельной проверкой.

## Динамика

Временной Leiden можно добавить после проверки границ территорий. Сравнение включает независимые месячные разбиения, умеренную связь между месяцами и полностью фиксированные метки.

Временная связь должна уменьшать случайные переходы, сохраняя заметные изменения. Совместный расчёт по всей истории описывает прошлое; для заявления об обнаружении изменений в реальном времени нужен другой протокол.

## Полезность экономических соседей

Проверю, насколько согласованно меняются заранее выбранные аналоги по сравнению с территориями того же региона, близкими по уровню расходов и случайными соседями.

Соседи выбираются только по данным до временного отсечения. Последующие значения используются для оценки сходства динамики. Это проверка на отложенном периоде, а не прогноз. Неопределённость можно оценить парным bootstrap по территориям, дополнив его проверкой пространственной зависимости.

## Дополнительные проверки

Проверю влияние географии, уровня расходов, удаления одной категории и способа соединения ближайших соседей. Для контроля самого метода нужны примеры с известными группами, одним непрерывным облаком и заданным временным сдвигом.

Если усложнение не даёт устойчивого улучшения, в основном результате останется более простой вариант. Перечень текущих результатов — в [статусе проекта](ACCEPTANCE.md).
