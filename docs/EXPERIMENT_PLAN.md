# Протокол следующего разрешённого эксперимента

Это подготовка, не запущенное обучение. Конфигурации не включают автоматический подбор.

1. **Pilot**: один development-срез (декабрь 2023), 2016 объектов, seed=1729; KMeans K=8, Ward K=8, Leiden resolution=1 на общем kNN k=15. Сначала подтвердить, что все три дают валидные outputs, сопоставимые метрики и понятные масштабы. При вырожденном разбиении исследовать причину, не запускать сетку.
2. **Сравнение 2023**: K∈{4,6,8,12}; k∈{10,15,30}; 3 seed для стохастических методов. Это не декартово произведение. Сначала ограниченная чувствительность по одному параметру, затем небольшая подтверждающая область. Сохранять фактическое K, размеры, связность, все ICVI и время.
3. **Фиксация**: по разделению, стабильности и понятности выбрать несколько Pareto-кандидатов. Зафиксировать конфигурацию до анализа 2024. Устойчивость не оценивать только по маленькому дрожанию временного метода.
4. **2024**: применить фиксированный способ построения/кластеризации; это новый независимый набор месяцев для подтверждения стабильности, но не ground-truth. Настройка по нему переводит его в development и должна быть отмечена.
5. **Временная регуляризация**: после проверки границ. Нулевая связь, умеренные значения omega, замороженные метки; контролируемые внедрённые сдвиги. Принять только если уменьшает ложные переходы и не стирает реальное изменение. Не выдавать joint fit за online inference.
6. **Независимая полезность**: сравнить согласованность последующих изменений у заранее выбранных аналогов с region/level/random на общей выборке. Cohort и соседи выбираются до отсечения. Масштабирование/настройка только до него. Это ретроспективная внешняя проверка: будущие изменения аналогов наблюдаются для оценки; такой расчёт НЕ является прогнозом с момента отсечения. Парный bootstrap по МО даёт первичную неопределённость, пространственная зависимость требует дополнительной блочной проверки.
7. **Контроли**: непрерывное облако, известные группы, перестановки временных сдвигов с сохранением сезонности, level-only, география, удаление категории, union/mutual. Старую синтетику Astra не повторять без новой проверяемой причины.
8. **Остановка**: если сложный компонент не добавляет воспроизводимой пользы, исключить его из основного результата и показать это сравнение. Не искать параметры до появления красивых экономических названий.

Статусы обязательных результатов — [ACCEPTANCE.md](ACCEPTANCE.md). Для краткой конкурсной работы важнее закрыть метрические определения и три содержательных кейса, чем добавить ещё одну нейросеть.
