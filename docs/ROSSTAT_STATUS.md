# Внешняя экономическая проверка: статус

Для внешней проверки я планирую использовать муниципальные данные по зарплатам и занятости. Подходящие таблицы пока не загружены и не сопоставлены с территориями.

Официальные маршруты:
- БД ПМО, инструкция экспорта: https://rosstat.gov.ru/free_doc/new_site/bd_munst/instruction.htm
- Описание набора показателей территориальным органом: https://35.rosstat.gov.ru/folder/120693/getPdf
- Пример паспорта с годами 2023/2024: https://rosstat.gov.ru/scripts/db_inet2/passport/table.aspx?opt=657010002023202420252026
- Региональные таблицы Алтайского края: https://22.rosstat.gov.ru/folder/33047

Описание подтверждает среднесписочную численность и среднемесячную начисленную зарплату работников организаций без субъектов малого предпринимательства, по МО и видам деятельности. Наличие подходящего файла с ОКТМО не проверено. Это не все занятые и не доходы жителей.

Следующий шаг — получить таблицу с единицами измерения, периодом и кодами ОКТМО, затем проверить полноту и однозначность сопоставления. Перечисленные ссылки пока служат отправной точкой для поиска, а не готовым источником внешней проверки.
