# Первая проверка по Росстату: Республика Алтай

Это описание ранней локальной проверки. Позднее собран [национальный набор внешних показателей](../reports/external-national-2026-10-03/README.md). Актуальные выводы, включая сравнение зарплат по уровню расходов и группам, приведены в [методике](NETWORK_TYPOLOGY.md#что-группы-говорят-об-экономике).

Сопоставлены по ОКТМО 11 муниципалитетов Республики Алтай за 2024 год. Использованы отгрузка организаций без субъектов малого предпринимательства и показатели коллективных средств размещения. Исходные ссылки, единицы, SHA-256 и мост идентификаторов доступны в [папке проверки](../reports/external/altai-2024/README.md).

Из 137 строк отраслевой отгрузки 55 содержат числовые значения, 77 закрыты и 5 отсутствуют. Закрытые и отсутствующие величины не заменены нулём. Файл занятости с кодами ОКАТО не присоединён к ОКТМО напрямую.

Проверка показывает пределы отраслевого именования: внутри одного потребительского профиля резко различается объём ночёвок и отгрузки. Один небольшой регион не подтверждает экономические типы на всей территории страны.

На момент этой локальной проверки национальный соединённый набор ещё не был собран. Последующее расширение сохранило проверку кодов, единиц, периодов и пропусков; его охват описан в национальном наборе по ссылке выше.
