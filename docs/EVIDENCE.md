# Выводы, файлы и воспроизведение

Здесь каждый вывод связан с сохранённым расчётом и существующей командой. Команды выполняются из корня репозитория в среде проекта. Команды с `--output` требуют нового файла или каталога; расчётные серии не перезаписывают прежние результаты. Скрипты сводок записывают собственные производные таблицы из сохранённых входов. Полные входы, версии и подготовка описаны в [REPRODUCE.md](REPRODUCE.md).

`validate_v12_findings` обновляет производные таблицы сохранённого пакета; `--check` повторяет их во временном каталоге и сравнивает с поставляемыми файлами.

## Дополнительные проверки основной модели

[Экономическая добавка](../reports/v1.2-added-value/README.md) сравнивает уровень, сплайн, группы и непрерывные отношения на одних наблюдениях с исключением региона. [Чувствительность выбора](../reports/v1.2-method-ties/README.md) повторяет ранжирование фиксированных разбиений на 500 региональных подвыборках. Команды повторения: `python -m scripts.check_added_value --check` и `python -m scripts.check_method_ties --check`. Полное повторение второго расчёта занимает около десяти минут по исходному протоколу; короткие тесты не заменяют этот расчёт.
