# Проверка скорости на точном пакете атласа

Выбор аналогов по шести признакам сохранил точные результаты и ускорился во всех восьми парных сравнениях. Лид разрешил внедрить только `sixNeighbors` и общий helper. Для архивной `nearest` общий заранее объявленный порог не пройден: одна из восьми пар показала замедление. Исходный план, все пары и `integration_rule_passed=false` сохранены; отдельное решение лида после известных исходов записано в `lead-decision.json`.

Опыт выполнен один раз 8 октября 2026 года, 21:22:01–21:22:32 UTC. Node v24.21.0, Windows x64, Ryzen 5 5600, одно ядро CPU3, один uv-поток, BelowNormal с переходом в Idle при перегрузке диска. V8 heap ограничен 512 MiB. Команда и SHA монитора находятся в `command-result.json`, версия Node и зависимости в первой строке `paired-raw.jsonl`. План SHA256: `074bb6a74557851b8ef663554f23ad608e23d19a8d20bbc27e674d09e17ab02b`. Журнал измерений SHA256: `509e7acee83c38c788b4389c6182d26913dd754e013d80d91430c48d699c2ce1`.

Пакет данных: `docs/assets/payload-f9d4a73c4edb9e7d5e0f2121183a87df5be296b43e73d510215ed7d00f34c75c.js`, 5 407 198 байт. Распакованный UTF-8 JSON занимает 18 917 633 байта, SHA256 `83dcd8ad60ba35a389c7737b7b5b90630870f3026f6b0cb41c5c39b03c4de610`. До замеров прошли 26 208 точных сравнений `DeepEqual` для всех 2016 МО и допустимых исключений, ещё 707 проверок равных расстояний, пустых и малых входов, NaN, отсутствующих признаков и необычного `count`. Числа не округлялись, допуск не применялся; самоисключение прошло для всех реальных результатов.

Подтверждён выигрыш преобразования base64 и суммарного сценария. Отдельного ускорения gzip или `JSON.parse` опыт не показал. Нативный `Uint8Array.fromBase64` отсутствует в этой версии Node и не внедрялся.

Монитор сохранил 43 выборки ресурсов. Максимумы: CPU 45,9%, RAM 85,54%, GPU 9%; минимум доступной RAM 2 472 763 392 байта. Диск C: достигал 100%, диск B: максимум 0,107%. При C: от 95% собственный процесс переходил в Idle с короткой паузой; пауз по CPU, GPU или RAM не потребовалось. В конце Node занимал 385 294 336 байт RSS; пиковый RSS и пики между выборками неизвестны. Первый короткий запуск только Python-монитора остановился до старта Node: bundled Python не имел `psutil`. Использован прежний Python 3.10; измеряемый Node запускался один раз.

Владелец `web/` внедрил `accepted-sixNeighbors.js`, SHA256 `bd5dbe68361606e72f4809b9648c08049413917cc167f92ddfbb51688d229d0a`. Это неизменённые helper и `sixNeighbors` из измеренного кандидата. Отдельная проверка `integration-six.json` прошла на template SHA256 `6e7b0874a87602390f457835e6bdda6f70a26f2beef1e04ef2abb1b538c5e4e4`: helper и `sixNeighbors` точно совпали с измеренными, архивная `nearest` и декодер сохранили исходник. Эта сверка кода не заменяет проверку браузера или готового HTML.

Доставляемый HTML, сеть HTTPS, холодный и тёплый кэш браузера, появление карты, полная сборка и CI остаются UNVERIFIED этим опытом. Новый вариант совместной сборки через `--standalone-output` реализует владелец сборщика; его время требует отдельного плана, точных окончательных SHA и отдельного вычислительного слота. Локальный браузер не запускался.
