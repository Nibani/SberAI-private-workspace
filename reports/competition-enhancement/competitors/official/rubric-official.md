6.3. Жюри оценивают работы по каждому из критериев по четырехбалльной шкале оценок:

• «плохо» (0 баллов);

• «удовлетворительно» (1 балл);

• «хорошо» (2 балла);

• «отлично» (3 балла).


**Критерии соответствия оценки созданного Проекта по направлению «Кластеризация» шкале оценки**

| № | Критерий | Шкала оценки по критериям Плохо | Шкала оценки по критериям Удовлетворительно | Шкала оценки по критериям Хорошо | Шкала оценки по критериям Отлично |

| 1 | Простота объяснения методологии | Присутствуют методологические ошибки | Методология в целом объяснена корректно, но есть существенные недостатки | Методология изложена понятно и последовательно | Методология изложена максимально ясно и полностью воспроизводима |
| 2 | Построение сетевой и атрибутивной структуры | Метод выбран без обоснования | Использован один подход с минимальным объяснением | Обоснован выбор метода и корректно построена структура | Выполнено сравнение нескольких подходов (корреляции, DTW, расстояния и др.), аргументирован окончательный выбор |
| 3 | Сравнение методов | Сравнение отсутствует | Сравнены отдельные методы без анализа | Проведено полноценное сравнение с выводами | Выполнено всестороннее сравнение с анализом преимуществ, недостатков и условий применения |

| 5 | Интерпретация результатов | Выводы отсутствуют или необоснованны | Есть описание результатов без анализа | Результаты интерпретированы, выводы подтверждены | Получены практически значимые выводы, результаты воспроизводимы и обоснованы |
