# Проверенные результаты v1.2

Исправленные расчёты воспроизводятся командой `python -m scripts.validate_v12_findings`. Она использует сохранённые таблицы сравнения методов и сетей, пересчитывает ошибки аналогов, диагностику выбора только по 2023, лаговые рёбра и 73 региональных разбиения. Полный поиск моделей повторять не требуется. `python -m scripts.validate_v12_findings --check` выполняет эти расчёты во временном каталоге и сверяет числа, прогнозы и хеши. Для отдельной копии задайте `--output runs/v12-checked`.

`analogues.csv` содержит четыре правила на общей выборке 2016 МО. Ошибки выражены в процентных пунктах арифметического роста `100*(mean_total_2024/mean_total_2023-1)`. Парные интервалы из `analogue_comparisons.csv` используют целые регионы с возвращением. `analogue_predictions.csv` сохраняет наблюдаемый рост, оценку каждого правила, ошибку и флаги общих выборок. Внутрирегиональная сеть требует минимум трёх других МО; шесть правил на общей выборке 2011 МО вынесены в `analogues_diagnostic.csv`. Интервалы условны на выбранную типологию и одну случайную выборку аналогов.

Выбранная α=0,5 сохранена. 2024 участвовал в выборе сети и модели, поэтому он служит валидацией и не даёт независимого теста. Диагностика выбора только по критериям 2023 находится в `summary.json`, поле `methods.selection_audit`; сам исторический выбор сети при этой диагностике не повторяется. Аналоги сравниваются ретроспективно по уже известным исходам других МО за 2024. Это сравнение не проверяет прогноз будущего года. Значения исходов 2025 не открывались.

`strict-region-validation/` содержит прогнозы, назначения, параметры всех разбиений, хеши состояния обучения и проверку независимости обучения от изменений исключённого региона. Калибровка, граф, KMeans, совместная модель, имена и экономический OLS обучаются без этого региона. Назначение исключённых МО использует ближайший обучающий центр без графа исключённого региона. Гиперпараметры зафиксированы по историческому глобальному выбору; вложенный выбор модели не проверяется. Строгие метрики записаны в `leave_one_region_out.csv`; прежняя проверка только экономической регрессии сохранена отдельно.

Административная категория, неизвестная на обучающей выборке с наблюдаемым исходом, получает среднее исхода обучающих МО. В объединённой модели для неё используется оценка только по типу. Прежний нулевой прогноз OLS сохранён в `admin_zero_prediction` и `municipal_type_original_zero`. Согласие новых назначений с типами полной панели сравнивает индуктивное назначение по центру с исходными графовыми метками и не измеряет только устойчивость переобучения.

Имена описывают расходы. Отрасль и география показываются отдельными наблюдаемыми характеристиками. Доли занятости относятся только к МО с данными; верхняя граница для всей панели не установлена. Пропуски могут сместить результат в любую сторону. Разрыв долей маркетплейсов считается между фиксированными типами 2023; его региональный интервал условен на наличие обоих типов в выбранных регионах и включает ноль. Лаговые рёбра отражают сходство рядов. Сохранение направления лага само по себе не доказывает причинную связь.

`findings_provenance.json` содержит хеши входов, кода, настроек, сохранённой сетки и исправленных результатов, а также версии библиотек. Строки и целые значения сверяются точно; для чисел с плавающей точкой в проверке воспроизведения допускаются `rtol=1e-10`, `atol=1e-12`. Полная команда `python -m scripts.run_v12` пересчитывает исходную сетку и затем выполняет исправленные проверки. Режим `--quick` служит только пробным запуском сокращённой сетки.
