# Правила проекта

- Прочитай CONTINUE.md и последние записи EXPERIMENTS.md.
- Не запускать обучение, кластеризацию, оптимизацию разбиения или подбор параметров без нового поручения Андрея. Подготовка и аудит разрешены.
- Исходные материалы и сырые данные неизменяемы. Не усреднять конфликты ключей, не выдавать название за ОКТМО.
- indicator_id из API — идентификатор серии, не территории.
- Сохранять хеши, происхождение данных, версии среды и фактические проверки. Не повторять синтетический опыт Astra без новой причины.
- Не называть найденные группы типами производства без независимых свидетельств. Ребро — сходство, не доказанный поток.
- MQ не заменять Newman Q; метрики вычислять на общих признаках и опорных графах.
- Сырые данные, входные архивы, локальные страницы сайтов и промежуточные результаты исключены из Git.
- Следовать ultra-research/research-workflow. Исполнителям выделять непересекающиеся файлы; критик не меняет проект.
