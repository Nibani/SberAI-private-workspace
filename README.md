# Экономические соседи

![Экономические соседи: исследовательский атлас муниципальных данных](docs/images/atlas-cover.svg)

Четыре группы показывают разные расходные профили муниципалитетов: три уровня общих расходов и отдельную группу с низкой долей маркетплейсов, высокой наблюдаемой зарплатой и низкой доступностью рынков. В атласе можно сравнить профиль МО с 15 аналогами и проследить изменения за 2023–2024 годы. Основная совместная модель α=0,5 учитывает пять отношений категорий к общему показателю и уровень расходов.

**2 016 муниципалитетов · 73 региона · 24 месяца 2023–2024 · СберИндекс**

## Три результата

Начните с трёх файлов: этого README, [краткого отчёта](docs/REPORT_RU.md) и атласа `docs/index.html`. [Инструкция просмотра](#посмотреть-атлас) объясняет, как открыть интерактивную страницу. Остальные документы и таблицы служат приложениями; их перечисляет [указатель расчётов](reports/README.md).

- В 2023 три группы различаются медианными общими расходами: 41,5, 25,9 и 20,0 тыс. руб. Четвёртая, с низкой долей маркетплейсов, имеет расходы 33,1 тыс. руб. и наблюдаемую медианную зарплату 90,2 тыс. руб. Зарплата есть у всех 127 МО этой группы; медиана доли добычи 24,5% относится только к 44 из 127 МО. Медианная доступность рынков составляет 138,1 при охвате 116 из 127 МО, у остальных групп 309,1–453,4. [Профили и охват показателей](reports/v1.2/types.csv).
- Похожие по структуре и уровню расходов муниципалитеты помогают точнее сравнивать их рост. На 2 016 МО средняя ошибка оценки роста расходов 2024 по 15 аналогам составляет 2,486 п.п.; по случайным соседям своего региона 2,701, по региональной медиане 2,628. Парные региональные интервалы подтверждают преимущество в этом сравнении. [Расчёт и практическое применение](docs/NETWORK_TYPOLOGY.md#как-использовать-аналоги).
- Четыре группы дают компактное описание расходного профиля. Для зарплаты уровень расходов даёт R² 0,734, группы 0,430; значимого прироста групп сверх нелинейного уровня после поправки на восемь показателей нет. В той же проверке значима только доля добычи; при общей поправке на 48 проверок значимого прироста нет. Сверх непрерывных отношений категорий выигрыш групп не подтверждён. [Сравнение зарплаты с уровнем](reports/v1.2/wage_level_comparison.json) · [Добавочная ценность групп](reports/v1.2-added-value/README.md).

Связи основной сети показывают сходство структуры и уровня расходов жителей. Атлас охватывает пять категорий; каждая сопоставляется с общим показателем расходов. Полный состав бюджета, поездки и денежные потоки требуют отдельных данных.

Экономические проверки связывают группы с наблюдаемыми зарплатами в основном через уровень расходов; связь групп с частью отраслевых показателей ограничена охватом данных. Для производственной типологии нужны более полные отраслевые данные. Эффект конкретных мер требует отдельного исследования причин и последствий. 2024 участвовал в выборе сети и модели. При отборе только по критериям 2023 выбирается α=0,1: отличаются 37 из 2 016 назначений, около 1,8%. Близость разбиений не означает устойчивость экономических выводов. Проверка на будущем периоде ещё предстоит.

Граф основной модели построен по тем же шести расходным признакам и сглаживает назначения KMeans. AVI, AVU и MQ на нём не дают независимого подтверждения; целевая функция не гарантирует улучшения каждого индекса. [Метод, фактические размены и архивная дорожная проверка](docs/NETWORK_TYPOLOGY.md#почему-четыре-группы).

Среди шести допустимых вариантов семейство совместной модели выигрывает в 99,4% из 500 региональных подвыборок, точное α=0,5 в 57,2%. Разбиения при других α различаются у 17–38 МО. Это проверка ранжирования фиксированных разбиений, без их переобучения. [Чувствительность выбора и размен между индексами](reports/v1.2-method-ties/README.md).

## Посмотреть атлас

Откройте локальный файл `docs/index.html` в браузере. Карта, поиск территорий и все сравнения доступны без установки.

Для просмотра без интернета скачайте репозиторий через **Code → Download ZIP**, распакуйте его и откройте `docs/index.html` в браузере. Сохраните рядом папку `docs/assets`: в ней лежат данные карты и расчётов. Python для просмотра не нужен.

1. Найдите муниципалитет в поиске или выберите его на карте.
2. Сравните профиль и 15 аналогов по структуре и уровню расходов. Проверьте муниципальный тип и уровень расходов; исключите категорию и посмотрите, как меняется список.
3. В «Динамике» сравните месяцы, а на карте 2023 с 2024, затем включите поправку на общую волну. В «Доказательствах и данных» показаны ошибки аналогов, изменения маркетплейсов и сравнения с KMeans4, H75, DMoN, Leiden и непрерывным ядром.

## Запустить проверку

Для полной проверки установите Python 3.10 или новее, зависимости из `requirements-models.txt` и Node.js 22 LTS или новее. Из корня репозитория выполните:

```sh
python -m pip install -r requirements-models.txt
python run_all.py
```

Команда последовательно проверяет входы, повторяет оба основных научных расчёта, запускает тесты атласа и проверяет его переключатели. Она показывает ход проверки и общий результат, сохраняет журнал и JSON в `artifacts/run-all`. Ошибка любого этапа даёт ненулевой код возврата. Проверка переключателей использует поддельный DOM; реальный вид карты и скорость сети проверяются отдельно. Режим `--quick` выполняет только быстрые технические проверки и оставляет научное воспроизведение непроверенным.

Два основных расчёта можно запустить отдельно:

```sh
python -m scripts.validate_v12_findings --check
python -m scripts.check_added_value --check
```

Первая команда проверяет основные экономические выводы и повторяет проверку с исключением каждого региона. Вторая пересчитывает сравнение групп с уровнем расходов и непрерывными отношениями категорий, включая bootstrap-t и поправки на множественные сравнения. Это проверка сохранённой исследовательской версии, в выборе которой участвовал 2024 год. Значения 2025 года в неё не входят.

Нужны `data/v12/panel.csv.gz`, `configs/v12.json`, входы Росстата и доступности рынков, указанные в этом конфиге, а также сохранённые результаты `reports/v1.2` и `reports/v1.2-added-value`. Они входят в комплект. Сырые архивы для этих двух команд не нужны. Если подготовленную панель требуется создать заново из первоисточников, выполните [подготовку основной модели](docs/REPRODUCE.md#19-сетевая-типология-и-проверка-аналогов); загрузчик проверяет версии исходных архивов.

Архивные модели и прежние пакеты отдельно проверяет `python -m scripts.verify_technical_core --output artifacts/technical-acceptance.json`. Команде нужен полный научный архив с четырьмя историческими пакетами; основной комплект для жюри содержит их сводки и выбранные результаты. [Состав и область архивной проверки](docs/TECHNICAL_ACCEPTANCE.md).

Для повторения расчётов нужны подготовленные исходные данные. [Инструкция](docs/REPRODUCE.md) содержит команды подготовки, обучения и сборки атласа. В [перечне проверок](docs/EVIDENCE.md) для каждого вывода указаны файл с результатом и команда воспроизведения.
